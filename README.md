# SNOW TIGER K

설호와 아빠의 야구 경기 기록 앱입니다. 이닝별 점수(R), 안타(H), 홈런을 기록하고 승률과 구단 순위를 봅니다.

- 설치형 웹앱(PWA)이라 홈 화면에 추가해서 앱처럼 쓸 수 있고, 인터넷이 없어도 열립니다.
- 기록은 사용하는 기기(브라우저) 안에만 저장됩니다.

## 설호 학습 플래너 (seolho-planner/)

설호의 주간 학습 시간표를 체크하는 앱입니다. 같은 저장소의 `seolho-planner/` 폴더에 들어 있고, 홈 화면에 설치할 수 있으며 인터넷이 없어도 열립니다. 기록은 사용하는 기기(브라우저) 안에만 저장됩니다.

- 자이언츠체는 (주)롯데자이언츠 배포 서체이며, 원본 파일을 변환·수정하지 않고 그대로 사용합니다.
